記録から分かること

    目的はエージェントの申告であり、必要性や正しさを証明するものではありません。同じ入力の繰り返しも、必要な再確認である可能性があります。

    すべての操作と根拠

    成否: success＝明示成功、error＝明示失敗、completed＝完了を観測・成否不明、started＝終了記録なし。所要時間にはhookの起動・待機が含まれます。

    ログの品質と観測範囲

    この欄はファイル全体の値です。フィルターで変わりません。未発火のhookは検出できず、欠落数は実際の未観測数の下限です。

    指標の読み方

    失敗率の分母はsuccess＋errorです。成否確認率の分母はsuccess＋error＋completedです。IDのないツールイベントは呼び出し数へ加算しません。曖昧な前後対応と時刻逆転は時間集計から除きます。並行実行の所要時間合計は実時間を超えることがあります。推論内容・能力評価・料金・トークン数は集計対象にありません。
