# 0007 開発の道具の版を ruff 0.17.1 と mypy 1.20.2 に固定する

- 状態：採用
- 関係するルール：PROC-03、TOOL-05、CODE-03

## 背景

配布物は Python 3.9 で動かす。開発の道具は `uvx` で版を固定して呼ぶ（[research.md](../research.md)）。

## 選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| ruff 0.16 系の最新 | 公開から日が経っている | 名指しされた技術のテンプレートに縛られる道具ではなく、古い版を選ぶ理由が無い |
| ruff 0.17.1（最新） | 最新のルール | 0.17 は公開から90日未満 |
| mypy 2.4.0（最新） | 最新 | `--python-version 3.9` を受け付けない |
| mypy 1.20.2 | 3.9 を対象にできる最新 | — |

## 決定

ruff 0.17.1、mypy 1.20.2 にする（既定値で決めた事項）。

## 理由

pattern-foundation の版の決め方の3（出たばかりのメジャー版を避ける）は、名指しされた技術のテンプレートと周辺の対応が追いついていない場合の規則である。ruff は開発の道具だけで使い、周辺との対応の問題が無い。mypy は 3.9 を対象にできる版に限られる。

## 影響

版を上げるときは、この ADR を置き換え、`Makefile` の `RUFF`・`MYPY` と research.md を直し、`make check` と `violation_probe.py` を通す（PROC-03）。
