# 0008 基盤の名前を autoflow-kit とし、分野を cli-library として扱う

- 状態：採用
- 関係するルール：なし（基盤全体の前提）

## 背景

pattern-foundation の命名規則は、指示で名指しされた技術の先頭2つに分野の語尾を付ける。今回の指示は技術スタックではなく、作りたいもの（オートフローのスキル）と参考の記事である。名指しされた技術は無い。

## 選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| 規則どおり `claude-cli`・`claude-lib` | 機械的に決まる | 中身を表さず、同じ作業場所の claude-review-kit などと見分けられない |
| `autoflow-kit` | 何の基盤かが名前で分かる。同じ作業場所の他の基盤（`*-kit`）とそろう | 規則から外れる |

## 決定

`autoflow-kit` にする（既定値で決めた事項）。分野は、配布物が「補助 CLI と、他のリポジトリに入れて使う部品」であることから cli-library とし、語尾の規則は適用しない。追加の軸は cli-library の X1・X2 に、X3〜X7 を足した。

## 理由

名前は、この基盤を初めて見る人が中身を推測できることを優先した。

## 影響

名前を変えるときは、ディレクトリ名、manifest の `name`、`pyproject.toml` の `name`、文書の題名を変える。
