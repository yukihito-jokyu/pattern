# ADR 0003: ソースプロジェクトのhooksも接続する

日付: 2026-10-24。状態: 採用。

収集スクリプトと導入処理は存在したが、ソースのClaude設定はfoundationの編集検査だけで、Codex設定は存在しなかった。この状態では、このパターン自身の操作は記録されない。

`.claude/settings.json`と`.codex/hooks.json`を配布物に含め、同じinstall.pyの`--in-place`で正本のrecord.pyへ接続する。既存の編集検査は保持する。別プロジェクトへの通常導入は共通スキルをコピーする方式を維持する。新しい収集器や別のログ形式は作らない。

qualityと契約テストは両設定の全イベントについてcollectorへの接続を確認する。設定の削除・切断を違反probeで検出する。導入テストは生成されたコマンドをサブディレクトリから起動し、合成入力の目的と結果が両製品のログへ入ることを確認する。

絶対パスは生成元の環境に属する。コピー・移動後は古い観測handlerを除いて再生成する。Codexの信頼は自動付与せず、再起動後に利用者が`/hooks`で確認する。合成入力の検証を製品の実セッション検証として報告しない。
