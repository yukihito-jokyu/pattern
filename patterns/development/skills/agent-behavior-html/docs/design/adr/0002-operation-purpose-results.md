# 操作・明示された目的・観測結果をv2へ記録する

状態: 採用。日付: 2026-10-24。

利用者から「何をしているか、なぜしているか」をログとHTMLで確認する依頼があった。v1はメタデータだけを保持していたため、対象・目的・結果抜粋を持つv2を追加する。旧ログは書き換えず、分析器はv1/v2の混在を読み、レポートをreport_version=2で出す。既存の時刻・成否・前後対応の意味は維持する。

操作はツール入力の選択したキーから取得する。目的はツール入力のdescription、または操作前にモデルがrecord.py --intentで申告したActionIntentだけを使う。プロンプトや履歴から推測した目的は入れない。UserPromptSubmit/SubagentStartのadditionalContextでセッション別の記録方法を案内する。製品側のhook信頼は利用者が行う。

ActionIntentは製品のhook名ではない。source・session・turn・agent・tool・入力指紋が一致する、申告後5分以内の次の1操作にだけ対応させる。複数候補では目的を特定しない。descriptionは説明用なのでv2の入力指紋から除外する。v1の保存済み指紋は再計算しないため、v1にdescriptionが含まれる場合はv2との比較が分かれることがある。

追加文字列はUTF-8のバイト上限を持つ。既知の資格情報形式をマスクする。Read/Write/Editのファイル本文、パッチの変更本文、プロンプト、transcript、環境変数は保存しない。Bashコマンドや出力に埋め込まれた任意の機密情報を完全に検出する保証は持たない。

HTMLはtextContentで操作・目的・出所・期待結果・観測結果を表示し、検索とJSON保存にも含める。欠落を未記録として表示する。デモは合成ログと明示する。CLI契約、目的の対応範囲・一回性・曖昧さ、マスク、上限、旧ログ互換、DOM実行で検証する。Claudeの実セッション検証は利用者の指示により省略する。
