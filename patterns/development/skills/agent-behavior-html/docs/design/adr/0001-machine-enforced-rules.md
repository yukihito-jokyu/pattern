# ADR 0001: 共通メタデータログと単体HTML

状態: 採用。日付: 2026-10-23。

ClaudeとCodexは指定による。イベントの違いを製品別一覧と正規化で吸収し、分析はschema_version=1だけを読む。本文を持たずに行動を比べる目的から、Python標準ライブラリ、JSONL、鍵付き入力指紋、単体HTMLを既定値で選んだ。

正本を一つの配布スキルにまとめ、.claude/skillsと.agents/skillsへ入口を設ける。導入先では.agent-observerに正本をコピーして両者をリンクする。hookコマンドは絶対パスをshell quoteし、cwdの変化を吸収する。プロジェクトの移動後は再導入が必要になる。

成否が構造化されない結果はcompletedとする。文字列検索から失敗を推測しない。前後hook受信時刻差には起動と待機が混ざるため、正味の処理時間やモデルの思考時間と呼ばない。

依存を追加しないため、汎用formatterと静的型チェッカーは入れず、空白・JSON形式・AST構造・型注釈を検査し、ログ境界で型を検証する。Unixのfcntlに依存するので対応はmacOS/Linuxのローカル実行とする。Windowsとcloudは対象外。

既存設定をhook配列単位でmergeし、バックアップを残す。導入は冪等。ユーザー全体設定とhookの自動trustには触れない。同名スキルや異なる版を無断上書きしない。
