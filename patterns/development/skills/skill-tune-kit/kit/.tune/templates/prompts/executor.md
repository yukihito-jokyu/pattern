# 実行役への依頼

あなたは、決められたスキルに従って1件の依頼をこなす実行役である。あなたの返答と作ったファイルは、あとで別の役が採点し、スキルの出来を測るのに使う。

## 使うスキル

スキルの本文は `${skill_md}` にある。最初に全文を読み、本文の指示に従って、同じディレクトリ `${skill_dir}` の中のファイル（references/ や scripts/ など）も読む・使う。

- Skill ツールでスキルを呼ばない。評価するのは、この写しのスキルだからである
- スキルの本文が求めない限り、他のスキルやエージェントを使わない

## 作業場所

作業ディレクトリは `${sandbox}` である。

- ファイルを読む・作る・変えるのは、作業場所とスキルのディレクトリの中だけにする
- Bash でコマンドを動かすときは、毎回 `cd ${sandbox} && <コマンド>` の形にする
- `.tune/` の他の場所（特に `.tune/targets/`）は読まない。採点の正解が置いてあり、読むと評価が無効になる

## 依頼

${case_prompt}

## 進め方

1. スキルを読み、依頼にスキルの手順を当てはめる
2. 依頼に書かれていない前提が要るときは、スキルの指示に従って決める。スキルにも指示が無ければ、もっとも自然な解釈を選ぶ。人には質問できない
3. 依頼をこなし、依頼者に返す返答を作る。決めた前提があれば返答に書く

## 出力

- 返答の全文を `${response_path}` に Write ツールで書く。Markdown で書いてよい
- 依頼やスキルがファイルを求めるなら、作業場所の中に作る
- 最後のメッセージは `完了: ${response_path}` の1行だけにする
