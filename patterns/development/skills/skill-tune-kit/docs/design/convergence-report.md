# skill-tune-kit 収束テストの記録

独立エージェント（この基盤の作成時の会話履歴を持たないセッション）に同じ課題を解かせ、書き方の違い（揺れ）を測った記録である。手順の詳細は、作成に使ったスキルの convergence-test.md にある。各ラウンドの生データは `.foundation/convergence/round-<R>/` にある。

## 条件

| 項目 | 値 |
|---|---|
| 実行方法 | `claude -p`（Claude Code 2.1.296）。manifest の `convergence.runner` のとおり `--permission-mode acceptEdits` と `--allowedTools`（Skill、`make *`、`python3 *`、`git diff`・`git status`、`tail`・`head`・`grep`・`ls`）で起動した。各コピーの CLAUDE.md、`.claude/skills/`、hooks が読み込まれる。ユーザー単位の `~/.claude/CLAUDE.md`（日本語で答える、生成物はプロジェクトの中に置く、などの一般的な指示）も読み込まれた |
| エージェントの人数 | 3人（課題ごと） |
| 課題 | `.foundation/convergence/tasks.json`（T1-add：検査の種類を足す、T2-change：学習役への指示にラウンドの番号と上限を入れる、T3-cross：status に今の版の検証用の成績を出す、H1-holdout：ラウンドの採否を一覧で見るコマンドを足す）。T1 は種類の名前をあえて書かず、既定値の表が効くかを測った |
| 合格基準 | files 1.0、names 0.8 以上、全員の出力が check を通る、保護ファイルを変えない、R1〜R6 の未対処が0件、レビュー検出率が全員 100% |
| 費用（runner が報告した値） | ラウンド1 11.34 ドル、ラウンド2 10.66 ドル、ラウンド3 18.36 ドル（レビュー 3.56 ドルは別） |

## レビュー検出率

仕込んだ違反は15件（`.foundation/convergence/review-seeds.json`）である。強制に review を含むルール13件（STR-02、CODE-01、CODE-05、STATE-01、STATE-02、STATE-03、OPS-03、TEST-02、PROC-02、PROC-03、PROC-06、PROC-07、TOOL-04）と、抜け道の TOOL-03（抑止コメント）・DEP-03（依存の追加）を、1件に1つずつ入れた。TOOL-03 以外は、機械の検査を全部通る形にした。

| エージェント | 検出率 | 余計な指摘 | 判定 |
|---|---|---|---|
| review/agent-1 | 100%（15/15） | CODE-04、PROC-04、STR-01 | 差し戻し |
| review/agent-2 | 100%（15/15） | CODE-04 | 差し戻し |
| review/agent-3 | 100%（15/15） | CODE-04、DEP-01、STR-01 | 差し戻し |

検出したルールIDの集合は3人で一致した。余計なルールIDは誤った指摘ではなく、説明の中で触れたものである。CODE-04 は、TOOL-04 の指摘で「`PLR0913` を外すと CODE-04 の引数の上限が効かなくなる」と理由を書いたものである。STR-01 は「ルール追加の提案」の節で、リポジトリ直下のファイル（`requirements.txt`）が置き場の表にも構造検査にも入っていないと指摘したものである。

## 結論

合格基準のうち、check、保護ファイル、レビュー検出率は全ラウンドで満たした。T1・T2 は全ラウンドで files・names とも 1.0 だった。

満たさなかったのは次の2つで、上限の3ラウンドに達したため打ち切った。

- T3 の names（0.556）：違いはテストの関数名だけで、R7 と分類した
- H1 の files と names：R1（表示だけのサブコマンドの置き場と名前）と分類し、決定表を足したが、効果は測っていない

続けて測るかは、利用者の判断に委ねる。続けるなら、H1 を見ていない課題として作り直し、決定表の効果を測る。あわせて、レビュー役が提案した「リポジトリ直下に置いてよいファイルを STR-01 の表に足す」かどうかも決める。
