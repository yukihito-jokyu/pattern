# 制御構文：Goの参照教材

## goal

条件による分岐と繰り返しの順序を追える。

## audience

Goを初めて学ぶ人。mainとfmtを使う最小の実行環境は用意できている。

## situation

- 場面: 置いて読ませる非同期の自習教材
- 持ち時間: 制限なし
- 1枚の字数の上限: 420字（上流の既定値）
- 受付値の根拠: 承認されたGo参照教材の計画に基づく既定値。個別スライドの人間確認は未実施。

## takeaway

条件による分岐と繰り返しの順序を追える。詳しい前提・完全な実行例・練習は外側の学習ページで読む。

## constraints

- 枚数: 2枚
- 言語: 日本語
- 納品形式: HTML
- キャンバス: 1600×900px
- 禁止: 外部通信 / スクリプト / 未出典の数値
- しきい値の変更: なし
- 構図予算: M=80 / frame=composition / axis=row / connector=64 / align=center-x
- コード例の実行環境: Go 1.27.3、2026-10-24に実行成功と出力を確認

## skills

- 調べた経路: このセッションの利用可能スキル一覧、指定されたhtml-deckの同梱資料
- デザイン・UI: この静的教材専用のデザインスキルはなし。html-deckのquality-contract.mdとwhitespace-theory.mdの数値を使用
- 図・ダイアグラム: html-deck/references/figures.md。6箱以下で線が交差しないインラインSVGを実測する
- データ可視化: なし。統計データを可視化する教材ではない
- 日本語の文章: 専用スキルなし。リポジトリのAGENTS.mdの説明基準に従う
- 材料の読み取り: Go公式言語仕様の静的HTML

## design

- palette: bg白、surface淡い灰、ink濃い紺、muted灰紺、line灰、accent青緑の6色
- 書体: 表示と本文はHiragino / Yu Gothic / Noto Sans JP / system-ui、等幅はSFMono / Menlo / monospace
- 文字サイズ段階: 18 / 24 / 26 / 30 / 36 / 60px
- 階層の修正: 3教材のコード側スライドで同じweak_hierarchy所見が出たため、本文26pxを維持して見出しを54pxから60pxへ変更した。しきい値は変更していない
- signature: 値の移動を青緑の矢印と箱で追い、説明との対応は外側の注目表示で補う

## accepted

ユーザーによる各スライドの確認は未実施。自動検査の成功と人間の承認を区別する。

- [critic] 02は1→learn 1、2→learn 2、3→review 3、4→本体に入らず終了という統合トレースで、反復と分岐の順序を最後まで示す。
