宣言の型とreturnが入出力の形を決める

入力にも出力にも型があり、returnで結果を呼び出し元へ渡す。

型とreturnの対応

func remaining(
    total int, completed int) int {
    return total - completed
}

入力の型：total / completed のint

出力の型：閉じ括弧の後のint

値を返す：return

関数の本体は計算を担い、mainは戻り値を受け取ってremaining 2と表示する。
