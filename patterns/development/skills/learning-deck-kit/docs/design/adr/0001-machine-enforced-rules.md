# 0001 資料と教材データを正本にし、表示を共通化する

- 状態: 採用
- 日付: 2026-10-24

学ぶ技術ごとにページと手順を自由に書くと、資料の更新方法や注目表示が作者ごとに分かれる。対象版・公式資料・学習順序をprofileに固定し、本文と注目点をlessonに置く。HTMLは共通rendererで生成する。

html-deckはユーザー指定による。固定commitを全体同梱し、出典とMIT・draw-ioのMITを保持する。二重ビューアを避け、各スライドを1600×900の同一origin iframeで表示する。親側のSVGが対象DOMRectを縮小倍率で変換する。入場アニメ後の位置更新は実コード調査から追加した。

Node22はプロジェクトの共通CIと合わせる既定値。runtimeに周辺ライブラリを追加せず、開発時にPrettier/ESLint/TypeScript/Playwrightを固定する。JSDocのcheckJsでNodeとDOMを分けて検査する。

Go1.27は公開から90日未満だが、利用アプリの新ランタイム採用ではなく、既存の基本構文のオリジナル教材例を利用可能な1.27.3で検証する。教材はGoの全機能を網羅するものとは説明しない。順序は前提を積み上げるためのローカル設計である。

生成スキルとサイト出力は所有マーカーと内容ハッシュを持ち、利用者の既存ファイルや手編集された生成物を無断で上書きしない。更新の入力をprofile/lesson/deckへ戻せるよう、生成物は正本にしない。
