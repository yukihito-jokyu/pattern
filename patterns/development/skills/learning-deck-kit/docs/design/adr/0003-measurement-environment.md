# 0003 独立測定の環境を明示する

- 状態: 採用
- 日付: 2026-10-25

最初のCLI測定は、教材追加3件の完了後に外部サービスの5時間利用上限（429）へ達した。途中の教材変更と未着手の横断変更を合格の出力として扱わず、`round-0-cli-interrupted`へ証跡を保存した。別のきれいなコピーを用意し、履歴を渡さないAgentツールへ切り替える。CLIが報告したモデルはGLM-5.1/GLM-5.2であり、代替実行と同じモデルによる継続測定とは扱わない。

代替実行では、prepare時のPATHがツールのシェルへ引き継がれずNode26になった。また、コピー外へのアクセス禁止が、準備済み依存symlinkの参照まで禁止すると読まれた。この環境差を解消するため、最初の3人全員へ同一の環境情報だけを補足した。課題の実装方法・ファイル・識別子・他者の出力は伝えていない。以後のコピーしたconvergence.pyはNode22でのprepareを要求し、その実行パスと依存symlinkの例外を全員同じプロンプトへ入れる。配布元のスキル原本は変えない。

Agentツールではコピー側のClaude hooksが自動実行されない。保護ファイル差分をdiffで確認し、検査の条件変更があれば不合格にする。実装内容と無関係な環境準備の補足も測定記録へ残し、独立性に関する条件を隠さない。
