# learning-deck-kit の全体像

プログラミング言語・フレームワーク・ライブラリについて、対象専用の学習スキルと学習項目ごとのHTML教材を作る。公式資料の取得・更新手順をスキルに保存するため、単発の解説から後の学習へつなげられる。

スライドは全体像を短く示し、前提・処理の流れ・完全な例・練習は外側へ置く。左右の説明を注目対象へ結び付け、不要なときは非表示にできる。

## 前提と既定値

ユーザーはhtml-deckを指定し、learning-deck-kitという名前と配置、Go参照例を含む計画を承認した。新規モードで作り、既存パターンと未追跡ファイルは変更しない。
指定のない部分は日本語、非同期自習、HTTP配信、Node22、初期注目ON、1学習項目2枚を既定とした。周辺runtimeライブラリは追加しない。

## 依存の範囲

CLIと生成済みページはNode標準ライブラリとWeb標準APIで動く。スライド制作と上流の実測にはPython3.14・uv・Chrome、開発検査には固定したnpm開発依存を使う。生成済みページの閲覧に開発依存は必要ない。
