# 0002 基盤名を skill-harness2-kit にする

- 状態：採用
- 関係するルール：STR-01

## 背景

pattern-foundation の命名規則（intake.md の2章）では、名指しされた技術が1つ（harness2）なので、名前は `harness2-<分野の語尾>`（cli-library の語尾は `cli`）になる。一方、同じ作業ディレクトリには、同じ目的（Claude Code のスキルを改善する）の基盤が `skill-tune-kit` と `skill-brushup-kit` という名前で並んでいる。

## 選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| 命名規則どおり `harness2-cli` | 規則と一致する | 兄弟の基盤と並べたときに、スキルを改善する道具だと分からない。CLI だけを配るように読める |
| `skill-harness2-kit` | 兄弟の基盤（`skill-*-kit`）と並び、何の方法で何を改善するかが名前で分かる | 命名規則から外れる |

## 決定

`skill-harness2-kit` にする。配布するスキルの名前は `skill-harness2`、補助 CLI の置き場は `.h2/` にする。

## 理由

名前の役割は、利用者が作業ディレクトリで道具を見分けることである。3つの基盤が同じ `skill-*-kit` の形で並ぶ方が、規則の機械的な一致より見分けやすい。

## 影響

命名規則から外れたことは、この ADR だけに記録する。基盤の中のファイル名・モジュール名は rules.md の規則どおりに決める。
