# 0006 mypy は 1.20.2 に固定する

- 状態：採用
- 関係するルール：CODE-03、TOOL-05、PROC-03

## 背景

配布物は Python 3.9 で動かす（DEP-03）。mypy の最新は 2.4.0 だが、2.x は `requires_python >=3.10` で、`python_version = 3.9` を対象に検査できない（research.md の「mypy 1.20.2」）。

## 選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| mypy 2.4.0 | 最新 | 3.9 を対象にできず、3.10 以降の API の混入を検出できない |
| mypy 1.20.2（1.x の最新） | 3.9 を対象に検査できる | 新しい検査の一部が使えない |

## 決定

mypy 1.20.2 を `uvx mypy@1.20.2` で呼び、`python_version = "3.9"` と `strict = true` で検査する。

## 理由

配布先で起動できないコード（`zip(strict=True)` など）を検査で落とすことの方が、新しい検査より価値が大きい。

## 影響

配布物の最低の版を 3.10 に上げるときに、mypy 2.x へ上げる。上げるときは PROC-03 に従う。
