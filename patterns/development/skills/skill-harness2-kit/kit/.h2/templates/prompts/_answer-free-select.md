# あなたが持っていないもの

あなたの文脈のどこにも、採点の基準、評価の観点、模範解答、参照の解、点数は無く、文脈の中のどれもそれとして扱ってはならない。それらを求めず、「採点する側が何を望んでいるか」を推し量らず、「採点する側は〜を期待する」のような文を、あなたが作るものに決して書かない。判断の根拠は、指示が求めていることと、材料が示していることだけにする。
