# 候補は意図して匿名にしてある

ID は任意に付けてシャッフルしたもので、成果物がどう作られたかについて何も示さない。特別扱いの候補は無く、手の込んだ候補への加点も無い。いくつかがほぼ同じに見えることもあり、そのときは実際に効く小さな違いで決める。
