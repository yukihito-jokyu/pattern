# 0006 検査の道具が受け付けない新しい構文を使わない

- 状態：採用
- 関係するルール：OPS-05、DEP-01、ASYNC-01

## 背景

2026 年に GitHub Actions へ新しい構文がいくつか入った。actionlint の最新版 1.7.12（2026-03-30）は、そのうちのいくつかをまだ知らない。

| 新しい構文 | 時期 | actionlint 1.7.12 | zizmor 1.31.1 |
|---|---|---|---|
| 同じリポジトリのアクションを `$/path` で参照する（推奨になり、`./path` は例外扱い） | 2026-07-30 | 不正な書式として落とす | `./` を `self-repository` 監査で指摘する |
| ステップの並列実行（`background`、`parallel` など） | 2026-05〜06 | 知らないキーとして落とす | — |
| concurrency の `queue` | 2026-05〜06 | 知らないキーとして落とす | — |
| `schedule` の `timezone` | 2026-03-19 | 受け付ける | 受け付ける |

`$/path` については、actionlint と zizmor が逆のことを求めるので、どちらかを止めないと検査を0件にできない。

## 選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| 新しい構文を使い、actionlint の指摘を設定で抑止する | 公式の推奨に沿う | 抑止した範囲の検査（式の型、未定義の参照）が全部効かなくなる |
| 新しい構文を使わず、zizmor の `self-repository` 監査を止める | actionlint の全部の検査が効く | 公式の最新の推奨（`$/path`）から1つ遅れる |

## 決定

検査の道具（actionlint と zizmor）の両方が受け付ける構文だけを使う。同じリポジトリのアクションは `./.github/actions/<名前>` で参照し、`.gha/zizmor.yml` で `self-repository` を止める。ステップの並列実行と concurrency の `queue` は使わない。

## 理由

actionlint を部分的に止めると、式の型の誤り、存在しない入力、shellcheck の指摘という、ワークフローを手元で確かめる唯一の手段を失う（TEST-01）。1つの監査を止める損は、actionlint の検査を失う損より小さい。

## 影響

- actionlint が `$/` と並列実行に対応したら、この ADR を置き換え、DEP-01 の表と参照実装を `$/` に書き換え、`self-repository` を戻す
- 配布先の作者が新しい構文を使いたいときは、実装せずに提案として報告する（AGENTS.md の「してはいけないこと」）
