# 0007 ランナーのラベルを版付きで固定し、Linux は ubuntu-24.04 にする

- 状態：採用
- 関係するルール：NAM-06、OPS-01

## 背景

`ubuntu-latest` などの `-latest` のラベルは、GitHub が指す先のイメージを変える。2026-10-19〜11-19 は `ubuntu-latest` が 24.04 から 26.04 へ移行中で、実行ごとにどちらに当たるか分からない（research.md の「ランナーイメージ」）。Ubuntu 26.04 は 2026-09-17 に GA になったばかりである。

## 選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| `-latest` | 更新を気にしなくてよい | 同じワークフローの結果が日によって変わる。移行中は実行ごとに変わる |
| `ubuntu-26.04` | 最新 | GA から 90 日未満で、入っているツールの版が落ち着いていない |
| `ubuntu-24.04` | 入っているツール（Python 3.12.3、gh、jq）が落ち着いている。run-report をランナーの python3 で動かせる | いずれ 26.04 に上げる作業が要る |

## 決定

`runs-on` には版付きのラベルだけを書く。Linux は `ubuntu-24.04`（arm64 は `ubuntu-24.04-arm`）、macOS は `macos-26`、Windows は `windows-2025` にする。

## 理由

同じワークフローを同じ入力で動かしたら同じ結果になることを優先する。run-report は依存を入れずにランナーの python3 で動くので、Python の版が分かっているイメージに固定したい。

## 影響

- 26.04 に上げるときは、この ADR を置き換え、NAM-06 の表と参照実装を変える。run-report が 26.04 の python3 で動くことを確かめる
- actionlint は `-latest` を正しいラベルとして通すので、`-latest` の禁止は構造の検査（`rules_nam.py` の `nam06_runners`）で縛る
