# 0002 サブエージェントは設計役・構築役・採点役・分析役の4つにし、実行役は claude -p で起動する

- 状態：採用
- 関係するルール：STR-05、STATE-02、OPS-05、ASYNC-01

## 背景

この基盤は、対象スキル（開発用のオーケストレーションスキル）を作り、評価し、直す。それぞれの作業を誰が受け持つかを決める必要があった。前提は次の3つである。

1. 対象スキルは、メインのセッションで動き、Agent ツールでサブエージェントを起動する
2. サブエージェントから起動したサブエージェントは、そのサブエージェントの道具の制約を受け、人に聞く `AskUserQuestion` を使えない（[research.md](../research.md) の「Claude Code のサブエージェント」）
3. 先例の skill-brushup-kit は、実行役をサブエージェントにして、`tools` から `Agent` を外していた。その形では、実行役の中でオーケストレーションスキルを本番と同じ条件で動かせない

## 選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| 実行役もサブエージェントにし、`Agent` を持たせる | 起動がスキルの中で完結する | 本番は1層目のメインのセッションで動くのに、評価は2層目で動き、条件が違う。費用と起動の数を実行ごとに測れない |
| 実行役を補助 CLI が `claude -p` で起動する | 本番と同じメインのセッションの条件で動く。実行の記録（stream-json）から起動・編集の主体・費用・時間を測れる。費用の上限を `--max-budget-usd` で付けられる | auto モードで起動が拒否されうる。実行に時間がかかり、Bash の上限を超えうる |

## 決定

- 実行役は、補助 CLI の `execute` が評価用のコピーの中で `claude -p` を起動する形にする。引数は `execute.command` だけで組み立てる（OPS-05）
- この基盤のサブエージェントは次の4つにする。どれも `tools` を列挙し、`Skill` と `Agent` を入れない（STR-05）

  | 役 | 名前 | すること | CLAUDE.md |
  |---|---|---|---|
  | 設計役 | `forge-designer` | charter とリポジトリの決まりから、対象スキルの役・手順・人の関所・報告の形を design.json に書く | 読む |
  | 構築役 | `forge-builder` | 承認した設計から作った骨組みを埋め、下書きのバンドルを書く | 読む |
  | 採点役 | `forge-grader` | 実行の記録と差分を読み、受け入れ条件・手順・報告の形を判定する | 読まない（`omitClaudeMd: true`） |
  | 分析役 | `forge-analyst` | 採点と実行の記録から原因を分類し、候補のバンドルを書く | 読まない（`omitClaudeMd: true`） |
- `execute` は時間がかかるので、forge-run は Bash のバックグラウンドで回す。`exec.json` のある実行は飛ばすので、止まっても同じコマンドで続きから回せる

## 理由

オーケストレーションスキルを評価するには、本番と同じ層で動かすことが前提になる。`claude -p` はメインのセッションと同じくスキルとサブエージェントを読み込み、Agent の `tool_use` と `parent_tool_use_id` を記録に残す（[research.md](../research.md) の「Claude Code のヘッドレス実行（claude -p）」）。設計役と構築役は、対象のリポジトリの決まりに合うスキルを書く必要があるので CLAUDE.md を読ませる。採点役と分析役は、判定と分析を charter と証拠だけで行わせるため、CLAUDE.md を読ませない。

## 影響

- テストでは `claude -p` を起動せず、`tests/support.py` の偽の起動関数が記録した実行の記録を返す（TEST-02）
- auto モードの利用者は、`Bash(python3 .forge/forge.py *)` の許可の規則を足す必要がある。README と forge-run に書く
- 実行役の数は課題の数 × charter の `budget.agents` で、ラウンドごとに今と候補の2回ある。費用の上限の見積もりを charter.md に出し、人が予算を決める
