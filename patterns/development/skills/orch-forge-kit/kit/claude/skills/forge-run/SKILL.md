# forge-run

このスキルは、承認済みの charter（ゴール・指標・評価課題）に沿って、対象のオーケストレーションスキルを良くする作業を進める。対象は、スキルとそのサブエージェントの組（バンドル）である。作業は次の順に流れる。

1. **最初の評価**：評価用のリポジトリのコピーごとに、補助 CLI が `claude -p` を起動して、対象のスキルを評価課題で使わせる（この起動を実行役と呼ぶ）。実行の記録から、サブエージェントの起動・編集・検査の結果を集め、採点役が判定し、指標を計算する
2. **改善のラウンド**：must の指標が足りなければ、分析役が原因を調べて候補のバンドルを直す。候補を同じ課題で評価し、今のバンドルと比べる。採るかは人が決める
3. **最後の評価**：ホールドアウトの課題も含めて評価し、評価課題に合わせすぎていないかを確かめる
4. **報告**：指標の推移、採った変更、人に判断してほしいことをまとめる

どの段階にいて次に何をするかは、補助 CLI の `status` が決める。あなたは `status` の指示に従って、コマンドを実行するか、サブエージェントを起動するか、人に聞く。段階を自分で判断して飛ばさない。

## 役割

| 役 | 担い手 | 受け持つこと |
|---|---|---|
| 実行役 | 補助 CLI の `execute` が起動する `claude -p` | 評価用のコピーの中で、対象のスキルに従って評価課題を1つこなす |
| 採点役 | サブエージェント `forge-grader` | 1つの実行の結果を、判定項目ごとに判定して grade.json を書く |
| 分析役 | サブエージェント `forge-analyst` | 足りない指標の原因を調べ、候補のバンドルを直して proposal.json を書く |

メインのセッション（あなた）は、補助 CLI の実行、サブエージェントの起動、人との対話だけを受け持つ。

## 手順

1. 引数で `target-id` を受け取る。無ければ `python3 .forge/forge.py targets` で作業領域の対象の一覧を出し、AskUserQuestion で選んでもらう
2. `python3 .forge/forge.py status --target <id>` を実行する。`段階:` に `（forge-goals）` が付いていれば `/forge-goals` で charter を決めるよう、`（forge-build）` が付いていれば `/forge-build <id>` でスキルを作るよう伝えて終える
3. 最初の評価がまだなら（`段階: 最初の評価の準備`）、下の「人に確かめること」の評価の開始に従う
4. `status` の出力の `次:` の行に従う。終えたら `status` に戻る。下の「繰り返すこと」の表のとおりに進め、`段階: 完了` が出るまで繰り返す
5. `段階: 完了` が出たら、`.forge/targets/<id>/report.md` を読み、下の「報告」の形で人に伝える

### 繰り返すこと

| 出力の行 | すること |
|---|---|
| `次: python3 .forge/forge.py execute ...` | Bash で `run_in_background` を true にして実行し、完了の知らせを待つ（実行役の全部が終わるまで、課題の数と charter の `executor.timeout_sec` に応じて長くかかる）。終わったら出力を読み、`その後:` のコマンドを実行する。途中で止まっても、同じコマンドで続きから回せる |
| `次: python3 .forge/forge.py ...`（execute 以外） | そのまま Bash で実行する |
| `次: 下の job をすべて Agent ツールで…` | 下の「サブエージェントの起動」に従い、続く `job` の行をすべて起動する。全員が終わったら `その後:` のコマンドを実行する |
| `次: <proposal.md> の所見を人に見せる` | 所見の表を見せ、`その後:` のコマンドを実行する |
| `次: <compare.md> と <proposal.md> を人に見せ、採用するかを聞く` | 下の「人に確かめること」の採否に従う |
| `段階: 対象スキルがバンドルの決まりを満たしていない` | 続く問題の一覧を人に見せ、人がバンドルの決まりに沿って直すか、`/forge-build` で別の名前のスキルを作り直すかを決めてもらう。あなたはスキルを直さない |
| 出力に `WARN` の行がある | 人に見せる |

### サブエージェントの起動

`job` の行は `job <エージェント名> <ラベル> <プロンプトのパス>` の形をしている。1行につき1回、Agent ツールを次の値で呼ぶ。

| Agent ツールの引数 | 値 |
|---|---|
| `subagent_type` | `<エージェント名>`（`forge-grader` か `forge-analyst`） |
| `description` | `<ラベル>` |
| `prompt` | `次のファイルを読み、その指示に従ってください: <プロンプトのパス>` |

- 同じ出力に並んだ `job` の行は、Agent ツールの呼び出しを1つのメッセージにまとめて起動する（並行に動かすため）
- `run_in_background` は false にし、全員の完了を待ってから次へ進む
- 返答は `完了: <パス>` の1行である。中身の確認は補助 CLI が行うので、返答を読んで判断しない
- 採点役・分析役が書くべきファイルを、あなたが代わりに書かない。出力が無ければ、同じ `job` をもう一度起動する

### エラーのとき

補助 CLI が `エラー:` を出したら、内容で次のように扱う。

| エラーの内容 | すること |
|---|---|
| 「上の実行の採点役を、同じプロンプトでもう一度起動してください」 | 挙がった実行の採点役を同じ `job` で起動し直してから、同じコマンドをやり直す |
| 「分析役に、この問題を直すよう添えて…」 | 分析役を、`prompt` の末尾に `前回の問題: <問題の一覧>` を足して起動し直し、propose をやり直す。2回続けて落ちたら、人に見せて判断を仰ぐ |
| 「charter が … 変わりました」「未承認」 | `/forge-goals` で charter を見直すよう伝えて止まる |
| 「prepare からやり直してください」 | エラーの全文を人に見せ、評価の作業領域 `.forge/work/<id>/` の該当する置き場を消してよいかを AskUserQuestion で確かめる。消してよければ消してから `status` に戻る |
| 「準備済み」「決定済み」 | `status` に戻る |

## 人に確かめること

- 評価の開始：`.forge/targets/<id>/charter.md` の「実行役の起動（上限）」と「費用の上限の見積もり」を見せ、AskUserQuestion で「始める（推奨）／止める」を聞く。既定: 人が答えられないときは始めない
- 各ラウンドの採否：`compare.md` の指標の表と推奨の理由、`proposal.md` の変更の表とバンドルの差分、S6（評価の側の問題）の所見があればそれも見せる。そのうえで AskUserQuestion で「採用する／採用しない／ここで止める」を聞く。推奨が「採用」なら「採用する」を、「不採用」なら「採用しない」を先頭に置いて名前の末尾に `（推奨）` を付ける。採用なら `採用なら:` の、採用しないなら `不採用なら:` のコマンドを実行し、ここで止めるなら何も実行せずに終える（次に `/forge-run` を呼べば同じ場面から続く）。既定: 人が答えられないときは、何も実行せずに止まる
- S6 の所見があり、人が charter を直すと決めたとき：採否を記録してから、`/forge-goals` で charter を見直すよう伝えて止まる。既定: 人が答えられないときは charter を変えずに続ける
- `WARN` の行（評価の間に元のリポジトリが変わった、実行役が打ち切られた）と、上の表に無いエラー：内容を人に見せ、判断を仰ぐ。既定: 人が答えられないときは止まる

## 報告

最後の返答に、次の項目をこの順で書く。

1. must の指標が最初と最後でどう変わったか（表）
2. 採った変更の一覧
3. report.md の「人に判断してほしいこと」の節の全項目
4. report.md のパス

## してはいけないこと

- 対象のスキルとサブエージェントを、自分の判断で書き換えること。バンドルを変えるのは `decide --adopt` だけである
- 採点・提案・比較のファイルを手で書き換えること
- charter を書き換えること。charter を変えるときは `/forge-goals` に戻る
- 人の答えを待たずに `decide` を実行すること
- 実行役（`claude -p`）を、補助 CLI の `execute` を通さずに起動すること。権限と予算の条件がそろわなくなる
