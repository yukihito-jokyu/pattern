# draw.ioでドメインモデル図を作る

業務の理解を、具体例で確かめられる図と判断メモにする。最終成果物は、全ページの図データを埋め込んだ `.drawio.png` と、その図を説明するMarkdown。画像に見えているページと、再編集用に埋め込まれた全ページは区別する。

## 業務を整理する

[モデリングの判断](references/modeling.md)を読み、入力にある目的・対象期間・前提・対象外を整理する。既存図の更新では、現在の意味・用語・未決事項も読む。図の種類が指定されていなければ概念モデルから始める。

具体的な出来事から、誰が何をどの対象に対して行うかをたどる。「出荷前」のように結果を変える語は、業務上のどの出来事を指すか確かめる。入力や資料で確定したこと、説明のための仮定、確認が必要な質問を分ける。不明な期限・多重度・例外処理を常識で確定しない。重要な不足は質問し、回答を待たずに進められる部分は未決の注記を付けた案として作る。

名詞を候補にしつつ、独立したライフサイクル・業務上の区別・守るルールを手掛かりに概念と属性を選ぶ。関連は業務上の読み方を付け、両端の多重度を具体例で確認する。各判断に、入力の記述・確認結果・仮定のいずれを根拠にしたかを残す。

概念モデルには業務用語の概念・必要な属性・関連・制約を描く。言語の型、実装メソッド、DBの外部キー、Repositoryは持ち込まない。状態変化は必要な状態遷移ページ、複数処理の順序は別の補助図へ分ける。

設計モデルを求められたときは、概念図とは別ページで、同一性を持つEntity、値として扱うValue Object、振る舞い、ルールを守る責務、不変条件と集約境界の候補を検討する。親子関係だけで集約を決めず、同時に成立させる必要があるルールから理由を説明する。Bounded Contextは用語・モデルの適用範囲であり、集約やマイクロサービスと同一視しない。

## 編集可能なPNGを作る

[draw.ioの作成と検査](references/drawio.md)に従い、XMLを直接作成して、概念・属性・関連・多重度など、モデルを表す要素を別々のセルとして定義する。多重度と関連名は接続線に結び付け、未決や設計候補は短いラベルでも識別できるようにする。

目的・対象範囲・用語の解説・凡例・仮定の根拠・設計理由・未決事項の一覧はdraw.ioの外のMarkdownへ書き、ページ名と要素名で図へ対応付ける。説明文を図の余白や別ページに並べない。図への補足が必要なら、まず接続・包含・境界・状態遷移などの図の構造で表す。それだけで伝わらない制約は、対象要素へ結び付けた短い制約ノートや遷移のガードで示す。

XMLは一時ファイルへ保存し、Desktop CLIで実際に描画して、**図のコピーと全ページを含めたPNGを書き出す**。アプリの画面操作は通常の作図に必要ない。最終ファイル名は `.drawio.png` にする。XMLの拡張子変更、スクリーンショット、図データのないPNGを最終成果物にしない。CLIを使えなければ、利用可能なエディターでの書き出しを代替手段とする。どちらも使えなければPNGの作成は未実施と報告し、途中XMLを完成品として渡さない。

既存ファイルの更新ではコピーで作業し、変更内容を確かめてから指定先へ保存する。画像変換や最適化で埋め込みデータが落ちることがあるため、最終ファイルを再検査する。

## 具体例で確かめて渡す

[判断メモのひな形](assets/model-notes.md.template)を対象業務の内容で埋める。目的から概念と関連、ルール、具体例、設計判断、未決事項へつなげる。入力にない項目を埋めるために要件を作らない。

通常・禁止・境界・再操作・競合・後続処理失敗のうち対象に関係する具体例を図へ当てはめ、結果を説明できない箇所を更新する。注文キャンセルの期限や返金方法など、別業務の作例の仮定を流用しない。

```sh
python3 <このスキルの場所>/scripts/validate_drawio.py <成果物.drawio.png>
```

構造検査の後、全ページをPNG画像で見て、文字切れ・重なり・線の対応と、モデルの関係を一目で追える配置を確認する。説明文を外へ移した後は、箱の整列・間隔・図の外周の余白も調整する。先頭以外のページもCLIで一時PNGへ書き出して確認できる。利用者が希望する場合などは追加で、draw.ioのGUIで全ページを開き、コピー上の編集・保存・再読み込みを確認する。GUI操作を通常の作図完了の必須条件にしない。自動検査は業務上の正しさ、図の読みやすさ、人間の合意を保証しない。

最終回答には `.drawio.png` と判断メモへのリンク、主要な判断、実施した検査、未決事項を示す。未確認の表示・再編集・業務判断を確認済みとしない。
