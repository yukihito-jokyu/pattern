# 0005 指示に無かった事項を既定値で決める

- 状態：採用
- 関係するルール：STR-01、DEP-04、STATE-01、OPS-02、OPS-04、TOOL-04

## 背景

ユーザーの指示は「Go で作る CLI のアーキテクチャパターン」で、確認した事項は次の3つだけである。

| 確認した事項 | 回答 |
|---|---|
| 引数の解析 | 標準ライブラリの `flag` |
| 配布の方法 | `go build` と `go install` だけ |
| Go の版 | Go 1.27（最新安定版） |

基盤を作るには、これ以外にも決めることがある。ここに、既定値で決めた事項とその理由をまとめる。

## 選択肢

事項ごとに、採らなかった選択肢を「決定」の表の「採らなかったもの」に書いた。

## 決定

| 事項 | 決めた値 | 採らなかったもの | 理由 |
|---|---|---|---|
| モジュールのパス | `example.com/go-cli` | GitHub のパス | 置き場のリポジトリが決まっていない。実際に置くときに `go.mod`、`.golangci.yml`（`local-prefixes`、`module-path`、`ignore-package-globs`）、`tools/archcheck` を一緒に変える |
| コマンド名 | `go-cli`（基盤名と同じ） | 業務を表す名前 | 基盤の見本なので、業務の名前を付けない |
| 参照実装の題材 | タスク（`task add`・`task complete`・`task list`） | 題材なし、ファイル操作の道具 | 作成・状態の変更・一覧の3種類の動詞、検証、見つからない場合の失敗、JSON の出力がそろい、全ルールを体現できる |
| 業務データの保存 | データディレクトリの JSON ファイル | SQLite、設定ファイル | 標準ライブラリだけで書け（DEP-04）、外部のプロセスが要らない |
| データディレクトリ | `$GOCLI_DATA_DIR` → `$XDG_DATA_HOME/go-cli` → `$HOME/.local/share/go-cli` | `os.UserConfigDir` | clig.dev が XDG に従うことを勧めている。`GOCLI_DATA_DIR` でテストや利用者が場所を変えられる |
| 対応する OS | macOS と Linux | Windows | `HOME` と XDG だけでデータディレクトリを決めるため。Windows に対応するときは `config.go` に分岐を足す ADR を書く |
| ファイルの権限 | ディレクトリ 0700、ファイル 0600 | 0755・0644 | 個人のデータを他のユーザーに読ませないため（gosec の既定の推奨とも一致する） |
| 外部の依存 | 使わない | 必要に応じて足す | 指示は `flag` だけを名指ししている。足すほど作者ごとの選択が分かれる |
| 検査の入口 | `Makefile`（GNU Make） | シェルスクリプト、`go run` だけ | macOS と Linux に標準で入っていて、ターゲット名で検査を分けられる |
| CI、ライセンス、リリースの自動化 | 置かない | GitHub Actions、GoReleaser | 指示の範囲外。配布は `go install` だけと確認済み |
| 時刻の精度 | UTC の秒単位 | ナノ秒、地方時 | JSON の出力とテストの期待値を1通りにするため（OPS-03） |

## 理由

既定値は、指示に名指しされた技術だけで動き、後から変えるときに触る場所が少ないものを選んだ。どの値も、変える場合に触るファイルを上の表に書いた。

## 影響

- モジュールのパスやデータディレクトリを変えたくなったら、この ADR を「置き換え」にして新しい ADR を書き、表に書いたファイルを一緒に変える
- Windows への対応、CI の追加は、この基盤の外の依頼として扱う
