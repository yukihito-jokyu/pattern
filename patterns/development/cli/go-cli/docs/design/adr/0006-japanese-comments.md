# 0006 コードのコメントを日本語にそろえる

- 状態：採用
- 関係するルール：CODE-08、CODE-10、OPS-03

## 背景

従来はコメントを英語、Go ファイル全体を ASCII に限定していた。ユーザーから「コメントは日本語で書いて」「ルールも日本語にしてください」と指示されたため、規約と検査と参照実装を一致させる。

## 選択肢

| 選択肢 | 良い点 | 悪い点 |
|---|---|---|
| 規約・検査・参照実装を日本語コメントにそろえる | 指示に従ったコメントで全検査を通せる | 定型文と違反例も更新する必要がある |
| 規約の説明だけを変える | 変更量が少ない | 日本語コメントが既存の検査で拒否される |

## 決定

コメントは日本語の1文を1行に書き、文末を「。」にする。宣言名で始める規則と、パッケージの説明の `Package <name>`・`Command <name>` の接頭辞は保つ。CODE-10 の定型文も日本語にする。

OPS-03 の ASCII 制限はコメントを除くコードに適用する。日本語の定型文を扱う `tools/` は文字列にも日本語を許可する。CLI の表示文字列と公開面の名前は従来のままとする。日本語の有無と文末は構造検査、説明の有無と名前の接頭辞は lint で検査する。英語のピリオドを検査する godot は外し、句点の検査を構造検査に移す。日本語の意味や1行に収めた文の内容は作者が確認する。

## 理由

日本語で規約を読む利用者が、コメントも同じ言語で理解できるようにする。定型文まで統一して、作者ごとの言い回しの差を抑える。

## 影響

AGENTS.md、実装用スキルとその見本、CODE-08・CODE-10・OPS-03、lint、構造検査、違反例、Go の参照実装を更新する。過去の検討記録は当時の記録として残す。
