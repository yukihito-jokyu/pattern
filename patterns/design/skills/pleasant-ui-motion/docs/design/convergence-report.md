# pleasant-ui-motion 収束テストの記録

この記録は、実装用スキルから同じ適用仕様を作れるか、レビュー用スキルが差分中の違反を見つけられるかを測る。対象は本キットの仕様と生成物であり、任意の利用アプリの実装や、人間の快適さを実証する試験ではない。

ラウンド1・2とその最終検査は初版の記録である。ユーザー確認で即時閉鎖の解釈が目標と異なると分かり、MOT-05を修正した。初版の合格を修正後のUX評価へ流用せず、末尾のラウンド3と再検証を区別する。

## 条件と判定

確認日2026-10-24、macOS。各課題を3人の独立セッションへ渡した。会話履歴を渡さず、他担当の出力や正解表もコピーへ入れていない。依頼文は `.foundation/convergence/tasks.json`、生の指標・差分は `.foundation/convergence/round-1/` と `round-2/` にある。

実行はAgentツールの代替方式。`claude -p` は起動後も結果を得られなかったため中止し、そのコピーを計測に流用せず、新しいコピーと独立セッションで開始した。原因は未特定。Agent方式ではコピー側のhooksが自動実行されないため、保護ファイルの変更をdiffで確認し、親側で全成果物の `npm run check` を実行した。

親の最終検査環境はNode.js 22.23.4、npm 11.20.0、Python 3.14。担当自身の検査には端末既定のNode.js 26.12.1／Python 3.15.0による実行や、準備失敗による未実施が含まれる。それらを固定環境での成功と混同せず、以下のcheck欄は親による再検査を表す。

初回の親検査では、uvランチャーがPythonの配置先をPATHの先頭へ追加し、Node.js 26.12.1／Python 3.15.0が優先されていた。バージョン出力から特定した後、Node.js 22.23.4とPython 3.14.9の実体を指す専用の探索順へ変更した。npmスクリプト内と同じPATHでも両バージョンを確認し、同じ21成果物を全て再検査した。作者の出力や基準を変更した再ラウンドではなく、実行条件を正した再評価である。

合格基準は全成果物のcheck成功、保護ファイル変更なし、files=1、names≧0.8、R1〜R6の未対処0件。最終ラウンドは初出のホールドアウトを含め、レビュー検出率を全員100%とする。contentも併記する。既定の上限3ラウンド、閾値の引き下げは行わない。

### 揺れ・実行上の問題と対処

| 対象 | 観測 | 分類 | 対処 |
|---|---|---|---|
| 仕様・生成物 | 作者間の差なし | 分類対象なし | 新ルールは追加しない |
| コピーの依存準備 | 外部リンクのため準備を止めた担当と、再導入した担当に分かれた。実行中に元の依存ディレクトリが空の状態も観測した | R3：実行基盤の隔離が不足 | 親が固定依存を復元し9成果物を再検査。次ラウンドでは各コピーへ依存の実体を用意し、共有リンクを除去。AGENTSへコピー内での再導入禁止を明記 |

共有依存を空にした操作の特定はできていない。依存の実体化は成果物の答えを教える変更ではなく、検査環境を分離する措置である。ルール・schema・業務文言の決定は変更しなかった。

## ラウンド3：開閉の修正

ユーザーは、アニメーションが「ぱっぱっと切り替わる」と指摘し、「待たせない」は次の動作に待機を生じさせない意味で、演出をなくす意味ではないと明示した。通常設定の往復の動き、途中反転、別操作、論理状態とフォーカスを分けるMOT-05へ修正した。詳しい判断はADR 0003。

| 原因 | 分類 | 対処 |
|---|---|---|
| 次の操作の待機と、見た目の継続を区別していなかった | R1 | 論理状態と表示の補間を分離し、通常時の往復をルールへ明記 |
| 即時hiddenを正解とし、中間状態を測っていなかった | R3 | 開く・閉じる両方の補間、4回の反転、別操作・フォーカスをブラウザーで観測。入力ロックと退出削除のprobeを検出 |
| 反転と別操作を両立する見本がなかった | R5 | CSS Gridとopacityのtransition、createDisclosure、独立した次操作ボタンを参照実装へ追加 |

Node.js 22.23.4／Python 3.14.9で、単体7件・Chromium7件、probe17/17と組み込み5/5が成功した。CSS transitionの時間を途中へ進めて止め、中間サイズ・透明度・反転位置を実際に測る。短い待ち時間の偶然や、見た目を消した状態を合格にしない。

修正後の追加課題T4-disclosureを3人の履歴を持たない独立担当へ渡した。全員が同じ3ファイルを変更し、files・names・contentは全て1.000だった。共通の新しい英字語は1個であり、命名全般の再現性を証明する結果ではない。生成された3仕様は全て`reverse`と`animated-nonblocking`を採用し、親側で各コピーの検査を実行して全員が成功した。

レビューも独立した3人へ渡し、全員が12/12ルールを検出した。余計なルールIDは0、検出集合は一致した。MOT-05では3人とも、単にIDを挙げるだけでなく、通常時の`panel.hidden = true`が退出の途中状態と反転を失わせる点を指摘した。各担当のブラウザー検査はローカル待受のEPERMで未実施だったが、これは検出率の成功と区別し、親側の実行許可された環境で参照実装と各実装コピーを検査した。

生の指標・レビューは`.foundation/convergence/round-3/`へ収録した。これは初版の追加・変更・横断・通知を全て繰り返す試験ではなく、変更したルールとスキルを対象にした再測定である。出力の一致と誤りの検出が成功しても、人間が実際に触ったときの気持ち良さを確認済みとは扱わない。
