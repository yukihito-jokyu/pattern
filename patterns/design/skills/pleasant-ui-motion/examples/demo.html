PLEASANT UI MOTION / REFERENCE

操作と応答をつなぐ

押した手応え、結果、次の操作を確かめるための動作見本です。

01 / FEEDBACK

保存の手応え

✓ まだ保存していません

デモ用に処理結果を選びます。実際の保存先へは送信しません。
02 / CONTINUITY

選択位置をつなぐ

連続して選ぶと、表示中の位置から新しい選択へ向かいます。

03 / CONTROL

動きはつながり、操作は続けられる

開く途中で閉じても、閉じる途中で開いても、そのときの見た目からつながります。

開閉の途中でも、次の操作を受け付けます。

補足

高さと透明度が連続して変わります。動きが終わる前でも、開閉を切り替えたり、隣のボタンを押したりできます。

時間と曲線は調査時点のTokenを参照しています。取り込み先のReact部品そのものや、快適さを実証した評価尺度ではありません。
