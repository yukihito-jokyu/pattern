# 0006 依頼に無かった事項を既定値で決める

- 状態：採用
- 関係するルール：CODE-04、OPS-03、STR-05、NAM-04、PROC-06、OPS-06

## 背景

依頼は「CLI 設計用のスキルを作成して」であり、指示は言語を問わないこと、引数の解析は標準ライブラリだけ、配布は言語ごとに可能にすること、の3つだった。次の事項は指示に無く、決めないと作者ごとに揺れるため、既定値で決めた。

## 選択肢と決定

| 事項 | 選択肢 | 決定 | 理由 |
|---|---|---|---|
| 文面の言語 | 日本語、英語、依頼ごと | 英語（ASCII）。OPS-03、CODE-04 | ヘルプの文面を全実装で同じ文字列にするため、文字コードの扱いの差が出ない ASCII にした。基盤の文書は日本語のまま |
| サブコマンドの段数 | 1段、2段、混在 | 操作が1つならルートだけ、2つ以上なら全部2段（`<名詞> <動詞>`）。STR-05 | 名詞を足しても既存のコマンドの形が変わらない。clig.dev が `noun verb` を多数派としている |
| 動詞の語彙 | 自由、gh 型（create・list・view・edit・delete） | gh 型の5つ。NAM-04 | clig.dev の「似た名前のコマンドを作らない」を、語の表で機械的に判定できる |
| 最初の版 | 0.1.0、1.0.0 | 1.0.0。PROC-06 | 0.y.z の互換性の約束が SemVer で弱く、版の計算（PROC-06）の規則が分かれる |
| 版の書式 | SemVer 全体、数字3つだけ | 数字3つだけ。OPS-06 | PyPI の公開版が SemVer のプレリリースの書式を受け付けない |
| 基盤名・スキル名 | — | 基盤 `cli-design`、実装用スキル `cli-design`、レビュー用スキル `cli-design-review` | pattern-foundation の命名規則（基盤名と同じ名前、レビューは `-review`）による |

## 影響

- 依頼が日本語のヘルプや別の動詞を明示した場合は、この ADR を置き換える ADR を書いてから変える（PROC-04）
- 実装用スキルの既定値表は、この ADR と rules.md の値を写したものである
