# はじめに

このサイトでは、技術の知識と作業の手順を文書として整理します。左のサイドバーで記事を選び、上の「文書を検索」からキーワードで探せます。

## 記事を読む

[記事を書く](./guide/writing.md)では、Markdownで記事を追加する手順を説明します。その後、[サイトを設定する](./guide/configuration.md)で、自分の用途に合わせた設定方法を確認できます。

## セットアップから始める

配布物のREADMEを開き、setupスキルまたはCLIを使ってサイト名と公開先を設定してください。サンプル値は利用者の決定ではありません。
