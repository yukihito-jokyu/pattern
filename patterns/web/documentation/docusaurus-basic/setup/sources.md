# 設定の出典と更新

対象はDocusaurus 3.10.2、TypeScript 6.0.3、Playwright 1.64.1。2026-10-18に公式ドキュメントとインストール済みの対象版を確認した。実際のソースハッシュと版はcoverage.jsonに記録する。

## 網羅する設定面

Docusaurus本体のConfigSchema、classic presetのOptions型と配下のdocs・blog・pages・sitemap・svgr・googleAnalytics・gtag・googleTagManager・themeの公開設定、theme-classicのThemeConfigSchema、文書front matter、カテゴリメタデータ、サイドバー項目、TypeScriptのcompilerOptions・watchOptionsとtsconfigルート、PlaywrightTestConfig、独自home・searchを対象とする。無効なpluginの設定も一覧に残す。廃止され使用禁止の項目もforbiddenとして表示する。

Reactとpicomatchは内部実装でAPIを呼ぶライブラリであり、独立した利用者向け設定ファイルをこのパターンでは公開しない。コンポーネントの全props、ブラウザーの全API、未導入pluginの全設定を列挙する意味ではない。自由な辞書のキーは利用者が追加するため、ワイルドカードで型を示す。

## 生成と検証

settings.catalog.jsonはOSSのJoiスキーマとTypeScript型から生成した設定台帳。子項目、配列、辞書、分岐、再帰型を含む。Joiが未公開のsidebar/categoryスキーマは、インストール済みのMITライセンスのソースをメモリーで読み、検証スキーマを取り出す。node_modulesは変更しない。

`npm run setup -- check` は、同じ採用版から再収集した全項目・構造・出典ハッシュを台帳と照合する。台帳同士の比較だけではない。型に書かれたJSDocをdescriptionへ保存するが、型に既定値がない場合は推測しない。computedDefaultは関数で決まる既定動作であり、JSONの値ではない。schema.typeがrecursiveの項目は、expressionに示す型を同じ構造で繰り返す。module/functionはローカルモジュール参照で指定する。

更新時は依存関係の版を変更し、公式差分を読んでからsetup/lib/catalog.mjsのcollectCatalogとcoverageOfで両JSONを再生成する。CLIの質問・反映・検証・代表的動作も確認する。ハッシュ不一致を無視する操作は用意しない。

## 質問の重要度

全項目にimportance（important・normal・advanced）とimportanceReasonを付ける。OSSの型にあるrequiredとは別に、このパターンの利用者が導入時に判断する重要度である。分類の保守元はsetup/lib/question-levels.mjs。サイト名・URL・言語・主要機能を重要、表示・運用を普通、内部処理・型・テストの詳細をadvancedとする。新しいOSS項目は原則advancedから確認し、利用者への影響を判断して分類を更新する。分類の変更後はcollectCatalogで台帳を再生成する。checkは分類も含めた一致を検証する。全台帳は残し、CLIとスキルが質問範囲を絞る。

## 値の優先順位

Docusaurusの既定値、パターンのサンプル値、利用者の回答を区別する。未設定はキーの省略、無効化はfalse、許可されたnullや空値はそのままの値である。

Docusaurus設定はsiteを基礎にし、classicの値はpreset、themeConfigはsite.themeConfigの上にtheme、サイドバーはsidebarを使う。customFields.patternはcustom専用である。site.pluginsとsite.presetsは追加分として引き継ぐ。プリズム配色はgithub/draculaを下地にtheme.prismで置き換える。baseUrlはSITE_BASE_URLがある場合だけ一時上書きする。CLIは保存値と実効値を両方示す。PlaywrightのwebServerが未設定の場合はテスト用の一時サイトを起動する。
